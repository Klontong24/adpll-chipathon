## Block Diagrams

### Bang-Bang Phase Detector (BB-PD)
**[Documentation](doc/bbpd.md)**

It is called a "bang-bang" phase detector because its operation is binary, producing only UP or DOWN decisions rather than a continuous-valued output. The term "bang-bang" originates from control theory, where a controller switches directly between discrete states instead of making gradual adjustments.

This block acts as the eye of the ADPLL, providing coarse sensing of the incoming reference clock (`tref`) and the feedback clock from the divider (`tdiv`), which is derived from the DCO output. 

If `tref` arrives earlier than `tdiv`, it indicates that the output frequency is too low and needs to be increased. Conversely, if `tdiv` arrives earlier than `tref`, the output clock is leading the reference clock, indicating that the output frequency should be decreased. 

### Proportional-Integral Digital Loop Filter (DLF-PI)
**[Documentation](doc/dlf_pi.md)**

It is a Proportional-Integral (PI) digital loop filter, which serves as the core mathematical brain of the ADPLL. The term "Proportional-Integral" stems from classical control theory, where a dual-path topology is utilized: a proportional path handles instantaneous phase error corrections to ensure loop stability, while an integral path tracks and eliminates long-term steady-state frequency errors.

This block acts as the coordinator or processing core of the ADPLL, smoothing out the high-frequency binary noise generated by the "bang-bang" phase detector (BBPD) and transforming it into a highly precise, stable frequency control word for the Digital-Controlled Oscillator (DCO).

Based on the binary direction signal (te_raw) from the BBPD, the filter dynamically scales the correction step magnitudes using configurable shift parameters (kp and ki). It securely accumulates these steps inside a guarded, saturation-protected register to prevent catastrophic underflow or overflow, and then combines the result with a mid-scale center code and optional dithering to generate the final bounded output (dco_code).

### LFSR Dithering (LFSR-DITHER)
**[Documentation](doc/lfsr_dither.md)**

It is a Linear Feedback Shift Register (LFSR) optimized for digital dithering, specifically designed to eliminate fractional spur patterns and quantization dead-zones within the ADPLL. The term "dithering" originates from digital signal processing, referring to the intentional injection of pseudo-random noise to spread narrow-band quantization errors across a wider, harmless frequency spectrum.

This block acts as a resolution enhancer or noise-shaper for the ADPLL, artificially boosting the effective fractional resolution of the DCO beyond its physical, discrete tuning-word limits by rapidly scrambling the sub-LSB frequency boundaries.

Utilizing a deterministic 16-bit seed configuration, the module executes multiple internal feedback loop steps per reference clock cycle to guarantee high-entropy randomness. When active (en), the raw pseudo-random stream is mathematically compressed via an arithmetic amplitude shifter (cfg_amp_shift) to deliver a perfectly zero-mean, signed output (dither) that perturbs the loop filter smoothly without introducing structural frequency offsets.
